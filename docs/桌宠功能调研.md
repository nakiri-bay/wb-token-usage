# 桌宠（Desktop Pet）开源项目功能调研

> 调研时间：2026-09  
> 目的：梳理 GitHub / 开源社区中主流桌宠项目的常见功能模块，为本项目（WorkBuddy 用量统计桌宠）后续增强提供参考。

## 一、调研到的代表项目

| 项目 | 技术栈 | 定位 / 亮点 |
|------|--------|------------|
| **OpenPets** (OpenPetsHQ/openpets) | Electron + 插件 SDK(JS 沙箱) | 桌宠平台，官方插件含专注计时、提醒、心情签到、小游戏、启动器、喝水提醒、虚拟宠物、系统资源监控、**Usage Buddy（显示 Claude/Codex 实时用量）** |
| **Clawd on Desk** (rullerzhou-afk/clawd-on-desk) | Electron + SVG | 监控 AI 编程助手（Claude Code / Codex / Cursor / Gemini 等），12+ 动画状态，权限审批浮窗，⭐ 5.9k |
| **VPet 虚拟桌宠** (LorisYounger/VPet) | WPF / C# | 可内嵌任意 WPF 应用，动画+自定义脚本，支持 Steam 创意工坊一键导入模组 |
| **Desktop-Pixel-Pet** (CanFlyhang) | Python + Tkinter | 像素宠物商城/解锁，以"运行时长"作货币，纯离线 |
| **DeskLLMPet** (isKage/desk-llm-pet) | Electron + WebM | 集成 LLM 对话（双击唤起聊天窗，流式响应），50+ 动画 |
| **desk-pet** (deepin 论坛) | C++17 / Qt6 QML | 番茄钟、日程提醒、天气、待办、便签、计算器，宠物头顶通知气泡 |
| **desktop-pet-kirby** (90shree) | Python + Tkinter | 物理引擎：重力、拖拽抛掷、边界弹跳、睡眠/漂浮 |
| **akitak1290/desktop-pets** | Python + Tkinter | 内置 Pet Creator 可视化编辑动作状态机（帧序列连线） |
| **TrayLife** (Microsoft Store) | 系统托盘像素宠物 | 基于使用习惯进化（蛋→史莱姆），实时 CPU 反弹速度，低内存/磁盘预警 |
| **Blanky** (Microsoft Store) | 系统监控宠物 | 对过热/低电量/高内存用对话气泡反应，桌面"觅食" |

## 二、常见功能模块归类

### 1. 形象与动画
- 透明无边框窗口 + 置顶（`overrideredirect` / `-transparentcolor`，Electron/Qt 同理）
- 帧动画 / GIF / SVG 状态机：待机、行走、漂浮、睡眠、思考、打字、建造、开心、报错、通知等
- 物理效果：重力、拖拽抛掷、边界碰撞反弹、地面摩擦（kirby / akitak）
- 随机待机行为，定时切换状态让宠物"显得活着"

### 2. 鼠标交互
- 拖拽移动（几乎所有项目标配）
- 单击 / 双击反馈：随机对话气泡、随机反应动画
- 右键菜单：设置、投喂、睡觉、更换桌宠、关闭
- 悬停手型光标、点击命中区处理
- 跟随鼠标 / 沿任务栏巡逻

### 3. 状态与养成（Tamagotchi 向）
- 虚拟宠物数值：饥饿 / 亲密度 / 精力，状态 HUD（迷你气泡 + 进度条）
- 成长进化：基于使用时长或 PC 习惯（TrayLife 按负载/网络/熬夜分型）
- 成就系统（TrayLife 12 项成就）
- 宠物商城 / 解锁机制（Desktop-Pixel-Pet，以运行时长作货币）

### 4. 效率 / 工具插件
- 番茄钟 / 专注计时（desk-pet、OpenPets 专注伙伴）
- 提醒类：喝水、休息、日程（可延后、音效、桌面常驻气泡）
- 待办管理（优先级条、过期标记、桌面悬浮卡片）
- 天气查询（Open-Meteo 免费 API、托盘 tooltip）
- 快速笔记 / 桌面便签（多窗口、7 色、独立持久化）
- 计算器
- 启动器 Launch Buddy（快捷键开文件夹/应用）
- AI 对话窗（DeskLLMPet，双击唤起 LLM）

### 5. 数据 / 系统监控展示（★ 与本项目最相关）
- 系统资源监控：CPU / RAM / GPU 占用、温度、网速 → 托盘 tooltip 或宠物身上仪表（OpenPets System Resources、TrayLife、Blanky、anan-thermal-monitor）
- **Usage Buddy / AI 用量展示**：直接读取本地 usage 端点，把 Claude / Codex 的实时用量显示在宠物身上 —— 这正是我们桌宠"今日用量 / 累计用量"的方向
- AI 编程助手状态可视化：思考/打字/权限请求/完成 → 用动画+气泡呈现（Clawd、Codex on Desk）
- 天气 / 时钟挂件

### 6. 平台 / 架构能力
- 技术栈多样：Python tkinter、Electron、Qt/QML、WPF
- 插件 SDK / 沙箱（OpenPets 的 `@open-pets/plugin-sdk`：权限、配额、存储、调度、面板、事件、音频、通知）
- 换肤 / 主题 / 模组市场（VPet 的 Steam 创意工坊、Clawd 三套主题 + 导入动画包）
- 可视化设置面板：透明度、缩放、动画池勾选
- 本地数据持久化（JSON）
- 开机自启
- 跨平台（Win / macOS / Linux）

### 7. 与 AI Agent 集成（新兴热点）
- 自动注册 hook，监控 agents 工作阶段
- 权限审批浮窗：一键"允许/拒绝"，全局快捷键（Clawd 的 Ctrl+Shift+Y / N）
- MCP 集成层（OpenPets 暴露标准 MCP 工具给 Claude Code / OpenCode 等）

## 三、对本项目（WorkBuddy 用量桌宠）的可借鉴清单

当前已实现：透明无边框窗口 + 置顶、AI 生成人物贴图、聊天气泡（今日/累计用量）、可点击刷新图标、15±2 分钟后台自动同步。

可优先借鉴、增强的方向：
1. **系统资源监控**：在气泡或侧栏加 CPU/内存占用（OpenPets / TrayLife 思路），让桌宠更"有用"。
2. **Usage Buddy 风格**：把"用量"做成更丰富的展示（今日、累计、趋势、剩余额度），参考 OpenPets 的 Usage Buddy。
3. **养成/状态数值**：给桌宠加"精力/亲密度"等轻量数值，用 HUD 气泡呈现，增强陪伴感。
4. **提醒类**：喝水/休息/定时提醒（可延后气泡），承接现有气泡 UI。
5. **换肤 / 设置面板**：透明度、缩放、形象切换，提升可玩性。
6. **跟随鼠标 / 拖拽移动**：让桌宠能在桌面走动（目前为固定位置）。
7. **点击对话**：单击随机弹一句俏皮话/鼓励语，复用现有气泡。
8. **开机自启**：当前自动同步已做开机自启，但桌宠本体开机自启尚未配置。
